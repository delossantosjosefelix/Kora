# Descripción

Kora es un sistema web de punto de venta orientado a minimarkets y colmados de la República Dominicana. La aplicación se ejecuta de forma local en el equipo del negocio y puede ser utilizada desde otras cajas conectadas a la misma red, por lo que no depende de servicios en la nube ni de una conexión permanente a internet.

El sistema centraliza la operación diaria del establecimiento: registro de ventas, administración del catálogo de productos con imágenes, control de inventario, compras a suplidores, gestión de caja por turnos, registro de gastos y generación de reportes de ventas y de ganancias. El acceso a cada función se define por roles de usuario, de modo que el Administrador, el Gerente y el Cajero dispongan únicamente de las operaciones que corresponden a su responsabilidad.

Los precios se almacenan como precio final, con el ITBIS incluido según la tasa asignada a cada producto: exento, 16 % o 18 %. El recibo interno presenta el desglose del impuesto, con el fin de que el cliente conozca el monto exacto que paga. El sistema incorpora además copias de seguridad de la base de datos y de las imágenes, así como mensajes y confirmaciones de interfaz diseñados a medida. Como etapa final se integra Kora AI, un asistente local que atiende consultas sobre productos y orienta en el uso de los procesos del sistema.

Se concibe como un prototipo académico desarrollado bajo las condiciones de un producto real.
